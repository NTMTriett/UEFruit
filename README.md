**A collection of fruit assets and related functionalities for Unreal Engine projects.**

This repository contains a variety of 3D fruit models, textures, and potentially Blueprints or C++ code to easily integrate interactive fruit elements into your Unreal Engine games or simulations. Whether you need apples for a marketplace, bananas for a jungle scene, or any other juicy additions, UEFruit aims to provide a ready-to-use solution.

## Features

* **Diverse Fruit Variety:** Includes a selection of common and potentially exotic fruit models. (Specific list to be added as the project evolves)
* **High-Quality Assets:** Models are created with attention to detail, featuring realistic textures and optimized poly counts for performance.
* **Ready to Use:** Assets are configured for easy drag-and-drop integration into your Unreal Engine levels.
* **Potentially Interactive:** May include Blueprints for actions like picking up, eating, or interacting with the fruit. (Depending on project development)
* **Well-Organized:** Assets are structured in a clear and logical folder hierarchy within the Unreal Engine project.

## Content Overview (Subject to Change)

The project currently includes (this list will be updated as more content is added):

* **Models:**
    * Apple (Red, Green)
    * Banana (Single, Bunch)
    * Orange
    * Strawberry
    * Watermelon (Whole, Slice)
    * *(More fruits to come!)*
* **Textures:** High-resolution color, normal, and potentially other relevant maps for each fruit.

* **Blueprints (Optional):**
    * `BP_PickableFruit`: A base Blueprint for making fruits interactable.
    * `BP_EdibleFruit`: Extends `BP_PickableFruit` with basic "eating" functionality (e.g., disappearing).
* **Example Map (Optional):** A simple level showcasing the included fruit assets.

## Installation

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/NTMTriett/UEFruit.git](https://github.com/NTMTriett/UEFruit.git)
    ```
2.  **Copy to Your Unreal Engine Project:** Navigate to the cloned directory and copy the `UEFruit` folder into the `Content` folder of your Unreal Engine project.
3.  **Open Your Project:** Launch your Unreal Engine project. The assets will now be available in your Content Browser under the `UEFruit` folder.

## Usage

1.  **Browse the Content Browser:** In your Unreal Engine editor, navigate to the `Content/UEFruit` folder.
2.  **Drag and Drop:** Simply drag the desired fruit Static Mesh or Blueprint (if available) from the Content Browser into your level.
3.  **Customize (Optional):** Adjust the scale, rotation, and material properties of the fruit instances as needed. If Blueprints are included, explore their details and customize their behavior.
